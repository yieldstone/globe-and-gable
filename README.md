# Globe And Gable

"Create a modern global real estate web application in English with a clean dark blue and white design. Include a top menu with: Properties, Mortgage Calculator, Post a Listing, Agencies, and a Language/Currency switcher (USD, EUR). On the home page, add a global search bar with filters (Country, City, Type: Buy or Rent, Price range, Size) and a grid of property cards with realistic global examples (apartments, houses, villas). Clicking a property opens a detail page with a photo gallery, map location, and contact button. Also include a working Mortgage Calculator page."
